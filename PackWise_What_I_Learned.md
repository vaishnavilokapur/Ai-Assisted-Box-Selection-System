what i learned from this assignment

Working on the PackWise project was a good way of getting a real understanding of how a real Django app works. It gave me a good grounding in how to create and manage models, how to link up the various bits of data, how to work with views and how to work with templates.

I also learned how to deal with multiple products and quantities in an order. The bit that really interested me was the box recommendation logic which takes into account product dimensions (and different rotations), the total weight and the box capacity before deciding on a box.

During development we learned the value of checking application logic, of finding the errors and of testing all the different scenarios. We also learned how valuable automated testing is in terms of ensuring the application behaves as it should.

Overall this assignment has given me a much better understanding of Django development, database relationships, problem solving and building an application from a set of real requirements.
